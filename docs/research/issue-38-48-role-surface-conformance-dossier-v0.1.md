## 0. Method, and what this dossier deliberately does **not** contain

* **Nothing here was executed.** No candidate binary, package, model weight, container or endpoint was installed, imported, run, or contacted; no vendor was provisioned; no trust store was changed; no synthetic or real data was sent anywhere; no benchmark was scored; no comparison was run.
* Every claim below is `source-inspected` (we read pinned public source **text**) or `claim/docs` (we read pinned public documentation). Per [#38](https://github.com/Marcus-Levin/hylja/issues/38)'s two-axis schema, **neither is `independently-executed`, and therefore every capability below has no observed outcome.** `UNKNOWN` means evidence was not established — not that a feature or risk is absent.
* Repository identity and licence conclusions are **not** repeated here except where a code file itself is the evidence; see the register and the Presidio dossier.
* Because no execution is authorised, every model, MCP, tool, file, shell, environment, skills, memory, web, handoff, telemetry, alternate-endpoint and direct-network surface is recorded as **untested / no observed outcome**, except where a pinned source file *states* a pass-through or an absent check. Those cells are marked `source-inspected statement`, which is still **not** an observed outcome.
* Versioning: every source citation is pinned to an immutable 40-hex commit and read on **2026-10-01**. Pinned = desk snapshot, not a pin of any eventual artifact bytes. Digests, signatures, attestations and dependency selection remain open per [#46](https://github.com/Marcus-Levin/hylja/issues/46) and the Presidio dossier.
* Fixtures used in the synthetic test plans in the [companion plan document](issue-43-68-synthetic-dev-test-plans-v0.1.md) are obviously synthetic and non-routable (`.invalid`, `example.com`, documentation IP ranges). No real-looking hostname, customer, employee, credential or secret appears in this repository.

## 3. Hosted-tool, streaming and redirect bypass requirements (normative for any later trial)

These are the bypass classes a future independently-executed arm must defeat before any cell can move to `enforced`. They are stated here so a later trial cannot quietly omit them.

1. **Hosted tool/agent surfaces.** Provider-hosted tool execution, and any provider-side retrieval or memory that a model can invoke, does not cross a local proxy. A cell claiming model-traffic coverage must state explicitly that provider-hosted execution is outside it (L3/K1 show this is not hypothetical).
2. **Streaming.** Any sink that emits token-by-token needs bounded holdback until an inspectable unit completes, with explicit negative cases for split secrets, out-of-order chunks, aborted streams, tool-argument deltas, and a decode/round-trip mismatch. K6's carry buffers are response-restoration logic, not a pre-send deny (O3 shows one candidate *reports* such a mismatch rather than blocking).
3. **Redirects and alternate routes.** Release must be checked against the **actual** routed destination and profile, not the requested URL. K2 relays redirects unfollowed, which means the final leg is not proxy-visible; a trial must capture the real sink or record the path as unobservable — never as passed.
4. **Non-listed hosts and paths.** A host allow-list (K1) is a coverage boundary, not a policy. Unlisted hosts, unmasked paths on a listed host, WebSocket transports and `chatgpt.com`-style alternative endpoints must each be exercised with planted synthetic values and reported individually.
5. **Bypass resistance and managed egress.** A local proxy plus a CA does not establish [#32](https://github.com/Marcus-Levin/hylja/issues/32). Only deployed, attested network controls support a complete managed-egress claim; direct-network bypass must be tested, not assumed, and any trust-store change is disposable-only with recorded cleanup.
6. **Zero sink bytes on denial.** For every denial — policy/review/context denial, classifier or sentinel outage, missing authenticated context, redirect to a different profile — the trial must show **zero bytes at the actual sink before any protected fragment leaves**, at pinned candidate + harness + configuration. A denied-flow observation that is not captured at the sink is *unobservable*, never a pass.
7. **Non-model sinks.** Shell, file, MCP, memory, Git/HTTP client, log and telemetry paths must be seeded with planted synthetic protected values too. Sanitized model traffic does not imply sanitized non-model traffic.
